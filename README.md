# Fajteris.lt Practice

Fajteris.lt Practice is a lightweight Minecraft PvP Practice plugin designed for Paper servers. It provides essential features for a PvP Practice server, including ranked and unranked queues, 1v1 duel arenas, various game modes, and a kit editor. The plugin is optimized for low memory usage and stable TPS, making it ideal for small-scale servers.

## Install

1. Download the plugin JAR file from the [GitHub releases page](https://github.com/EnderDevelopment/Fajteris.lt-Practice/releases).
2. Place the JAR file in the `plugins` folder of your Paper server.
3. Restart or reload your server to load the plugin.

## Use

1. Join the server and use the `/ciao` command to greet yourself.
2. Interact with NPCs to join queues and select game modes.
3. Use the kit editor to customize your kits.
4. Compete in ranked and unranked matches to improve your ELO rating.
